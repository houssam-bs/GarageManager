# GarageManager

## Présentation

**GarageManager** est une application Desktop de gestion d’un garage mécanique, développée dans le cadre d’un projet académique en Génie Informatique.

L'objectif est de centraliser les informations relatives aux clients, aux véhicules, aux réparations et aux pièces de rechange afin de faciliter les opérations quotidiennes d'un garage.

## Fonctionnalités prévues

- Gestion des clients
- Gestion des véhicules
- Gestion et suivi des réparations
- Gestion du stock des pièces de rechange
- Recherche et consultation des informations

Le périmètre fonctionnel détaillé est défini dans le Cahier des charges et les Exigences du projet.

## Technologies

| Technologie | Utilisation |

- `maquettes/` : prototypes de l'interface
